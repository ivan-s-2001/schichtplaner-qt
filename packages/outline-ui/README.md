# @qt/outline-ui

Внутренняя React-библиотека интерфейса QuickTickets, основанная на визуальном языке Outline.

## Цели

- один набор токенов для светлой и тёмной темы;
- одинаковая геометрия кнопок, полей, вкладок, диалогов и поверхностей;
- отсутствие CSS-имитации компонентов в каждом приложении;
- совместимый API для постепенной миграции Schedule;
- возможность последующего выделения пакета в отдельный репозиторий.

## Подключение

```tsx
import { Button, Input, PageHeader } from "@qt/outline-ui";
import "../../packages/outline-ui/src/styles.css";
import "../../packages/outline-ui/src/components.css";
```

В текущем репозитории пакет подключается через TypeScript path alias, поэтому новые зависимости и изменения `package-lock.json` не требуются.

## Компоненты первого релиза

- `Button`;
- `Input`, `Textarea`, `NativeSelect`, `Field`;
- `Tabs`, `Tab`;
- `Card` и связанные части;
- `Badge`;
- `Dialog` и связанные части;
- `PageHeader`, `PageToolbar`, `DataPanel`, `StatePanel`;
- `MetricGrid`, `MetricBlock`, `InlineNotice`.

## Правила

1. Значения цветов и размеров не дублируются в компонентах приложения.
2. Новые общие элементы сначала добавляются сюда, затем используются в Schedule.
3. Специализированные редакторы графика используют базовые компоненты пакета, но остаются в доменном слое Schedule.
4. Пакет пока `private`, поскольку перед внешней публикацией требуется отдельная проверка лицензирования производных стилей Outline.
