# Планирование отпусков

- Отпуск назначает администратор или руководитель выбранного подразделения.
- Сотрудник видит собственный баланс и периоды, но не создаёт отпуск самостоятельно.
- Годовой лимит хранится отдельно для каждого сотрудника и года; значение по умолчанию — 20 рабочих дней.
- Руководитель или администратор может изменить лимит в диапазоне от 0 до 366 дней.
- В расход идут только понедельник–пятница. Суббота и воскресенье внутри диапазона не списываются.
- Новый отпуск сразу получает статус `APPROVED`.
- Пересекающиеся периоды отсутствия запрещены.
- При назначении отпуска смены и назначенные выходные в выбранном периоде очищаются.
- Отпуск создаётся и редактируется только на странице `/employees/absences`; через ячейки графика он доступен только для просмотра.
